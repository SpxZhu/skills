# sgrill-with-docs

1. 先读取[决策呈现与执行确认](../_shared/grill-interaction.md)，作为本次调用的呈现与收尾规则。
2. 加载 `mattpocock-skills:grill-with-docs` 及它要求的依赖，按源技能执行。宿主支持调用时使用技能工具；否则从已安装技能中定位并读取对应 `SKILL.md`。必需依赖缺失时报告缺失项并暂停，不以本包装替代源流程。
3. 源技能负责事实调查、设计树、每轮问题、领域文档及完成判定；准备向用户提出决策时应用共享呈现规则，全部决策完成后应用共享执行确认规则。

本技能只适配决策呈现与最终执行确认。保留源技能的调查分工、并行方式、追问顺序和等待条件；源技能及其依赖文件保持原样。

领域文档按源技能的触发条件和时机处理：术语一经解决即记录，ADR 按源技能条件提出。文档写入遵循目标仓库规则与已有授权；写入受限时提供草案。此类讨论记录不受方案实施门禁延迟，也不构成实施授权。
